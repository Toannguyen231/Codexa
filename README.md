## 🎯 What is CodeRoom Frontend?

**CodeRoom Frontend** is a cutting-edge Single Page Application (SPA) designed to deliver desktop-grade code editor performance directly in your browser. Powered by **React 19**, **Vite 8**, and Microsoft's **Monaco Editor**, it bridges the gap between collaborative productivity and competitive esports programming.

---

## ✨ Features That Empower Developers

### 🔄 1. Multiplayer Collaborative Coding
- **Zero-Friction Sync**: Real-time keystroke propagation via Socket.IO with a 300ms debounce engine and strict anti-echo protection.
- **Visual Presence**: Watch teammate cursors glide across the file in real-time with personalized color identifiers.
- **Snapshot Versioning**: Revert accidental changes instantly using the built-in 20-slot snapshot history panel.
- **In-Room Chat**: Communicate with your team and paste code snippets without switching windows.

### ⚔️ 2. 1v1 Battle Arena (PvP Mode)
- **Ranked Matchmaking**: Enter the matchmaking queue to clash against developers near your ELO tier.
- **Direct Challenges**: Send invite links or challenge friends by their username.
- **30-Minute Rush**: Solve algorithms under pressure with live opponent progress trackers and countdown timers.
- **Instant Result Evaluation**: Automatic testcase evaluation with score and ELO updates upon submission.

### 🤖 3. Streaming AI Assistant (Gemini 2.0 & DeepSeek)
- **Token-by-Token SSE Streams**: Get instant responses rendered with a typing animation.
- **Explain, Fix & Optimize**: One-click actions to debug complex compile errors or understand time/space complexities.
- **Codebase-Aware Chat**: Converse with AI that reads your active editor context.

### 📋 4. Codeforces Online Judge & AI Hidden Tests
- **MathJax Math Rendering**: Read competitive programming problems with rendered LaTeX formulas.
- **AI Hidden Testcases**: Automatic evaluation against synthetic edge-case tests generated by AI.
- **7-Language Execution**: Run and verify C++, Python, Java, JavaScript, TypeScript, C#, and PHP code in seconds.

### 🏆 5. Gamification & Progression
- **7 Tiers of Glory**: Iron, Bronze, Silver, Gold, Platinum, Diamond, Grandmaster.
- **Daily Challenges & Streaks**: Never miss a day — maintain your streak and unlock unique badges.
- **Activity Heatmap**: A GitHub-inspired annual activity grid tracking every solved problem.

## 🏛️ Frontend Architecture

```
app_code_realTime/
├── src/
│   ├── component/
│   │   ├── Admin/             # Admin Dashboard & system oversight
│   │   ├── Battle/            # BattleHub, BattleQueue & BattleRoom
│   │   ├── Editor/            # Monaco Editor integration & terminal panel
│   │   ├── AIPanel/           # Streaming AI Assistant UI
│   │   ├── Problems/          # Problem catalog & ProblemPage runner
│   │   ├── Profile/           # User stats, rank badges & Activity Heatmap
│   │   ├── RoomMenu/          # Room creator & directory
│   │   ├── Login/             # Authentication & registration forms
│   │   └── AuthPages.jsx      # Password reset & email verification
│   ├── hooks/                 # Custom hooks (useSocket, useAuth)
│   ├── landing/               # Product landing page
│   ├── monaco/                # Monaco themes, keybindings & syntax definitions
│   ├── services/ & utils/     # REST clients & Socket handlers
│   ├── App.jsx                # Client-side routing with React Router v7
│   └── CodeApp.jsx            # Core multiplayer workspace
├── index.html
├── vite.config.js
└── package.json
```

## 🚀 Quick Start

### 1. Requirements
- **Node.js** >= `20.x`
- **npm** >= `10.x`

### 2. Installation
```bash
# Navigate to frontend folder
cd app_code_realTime

# Install dependencies
npm install
```

### 3. Environment Setup
Create a `.env.local` file:
```env
VITE_API_BASE_URL=http://localhost:5000/api
VITE_SOCKET_URL=http://localhost:5000
```

### 4. Run Development Server
```bash
npm run dev
```
Navigate to `http://localhost:5173` to start coding!

---

## 🌐 Deploy to Vercel

```bash
npm run build
```
Connect your GitHub repository to [Vercel](https://vercel.com/), select **Vite** preset, set `VITE_API_BASE_URL` and `VITE_SOCKET_URL`, and deploy with one click.
